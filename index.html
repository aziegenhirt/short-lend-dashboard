Fee Data. Rows tagged IBKR actual come from the IBorrowDesk feed — Interactive Brokers' published intraday borrow fee. Rows tagged modeled use an empirical curve calibrated to Engelberg-Reed-Ringgenberg (2018) and Drechsler-Moreira-Savov (2017), mapping SI %float and days-to-cover onto expected borrow fee, with a small-cap price premium. Modeled values are directional estimates, not broker quotes. Modeled rows get a small score penalty so actual data ranks first at ties. Free bulk borrow-fee data is scarce — this hybrid keeps coverage broad while flagging what's measured vs. inferred.
Methodology. Lending Score (0-100) weights borrow fee (40), SI %float (25), days-to-cover (15), price-eligibility (10), and data completeness (10). Modeled-fee rows are penalized 8 pts. Estimated Lender APY assumes a 50% split of the annualized borrow fee — typical of Fidelity FPL, Schwab SLFP, and IBKR Stock Yield Enhancement Program. Flags trigger at CTB thresholds: ≥100% extreme, ≥25% hard-to-borrow, ≥10% elevated, ≥3% warm. Modeled flags carry an "(est)" suffix.
Sources: IBorrowDesk (IBKR fees), HighShortInterest.com (FINRA SI% + float), StockAnalysis.com (SI% cross-check), Yahoo Finance (price, mkt cap, DTC). Refreshed daily via GitHub Actions.
Educational tool only. Not investment advice. FINRA short-interest data is bi-weekly; broker CTB rates move intraday.
